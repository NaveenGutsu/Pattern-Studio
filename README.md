# Retro Arcade Pattern Studio

A fun, interactive command-line tool built with Python that generates custom geometric shapes and number ladders using nested loops and character matrix logic.

---

# Features

* **Multiple Shapes:** Choose from Staircase Triangles, Diamond Gems, Number Ladders, and Hollow Frames.
* **Dynamic Sizing:** Pick any grid scale (e.g., 5, 8, 12) to resize patterns instantly.
* **Pure Python:** Zero external libraries required—runs anywhere right out of the box.

---

# How It Works

Pattern programming is like digital LEGO building:
* **Outer Loops** control the rows (moving from top to bottom).
* **Inner Loops** control the columns (placing spaces, numbers, or stars from left to right).
